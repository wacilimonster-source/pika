## 0. 一句话结论

在**作品详情页**与**作者页**提供两条复制路径：顶栏可见入口（详情页「更多」菜单、作者页复制图标）与文本长按快捷。复制遵循「所见即所得」——详情页复制完整原署名，作者页复制当前浏览署名。统一用 Snackbar 反馈；不改动任何点击语义，不在列表卡片上新增长按复制。

## 1. 需求理解与现状

### 1.1 用户要复制什么、为什么

| 内容 | 典型用途 | 关键诉求 |
|---|---|---|
| 作品名 | 站外搜索同作、发给朋友、记入待看清单 | 一个字都不能错，尤其是日文原名、长标题 |
| 作者名 | 搜作者其他作品、站外检索、记录联合作者/译者 | 复合署名要能整串复制；也要能只复制其中某一段 |

这个需求不是「分享」的替代品：分享会把「《作品名》 作者名 + 来源」一起发出去，而复制往往只要其中一个字段，粘贴到搜索框或其他 App。

### 1.2 现状（代码级核实）

| 位置 | 现状 | 依据 |
|---|---|---|
| 详情页顶栏 | 仅「收藏」「分享」两个动作，无复制入口 | `ui/detail/ComicDetailScreen.kt:146-189` |
| 详情页标题 | 普通 `Text`，不可选、不可长按 | `ui/detail/ComicDetailScreen.kt:794-799` |
| 详情页作者行 | 整行 `clickable`，点击进作者页/弹作者选择层；无复制 | `ui/detail/ComicDetailScreen.kt:800-821` |
| 详情页分享 | 文本为「《标题》 作者\n（来自 PiKA 漫画阅读器）」，不能只取单项 | `ui/detail/ComicDetailScreen.kt:169-186` |
| 作者页顶栏 | 标题为当前检索署名，仅「收藏」动作，无复制、无 SnackbarHost | `ui/author/AuthorScreen.kt:126`、`:130-153` |
| 作者选择层 | 片段 chip 点击即搜索；「完整署名」按钮点击即搜索 | `ui/author/AuthorPickerSheet.kt:74-107` |
| 阅读器 | VM 已持有 `comicTitle` / `comicAuthor`，但阅读面板顶栏显示的是章节名，未消费这两个字段 | `ui/reader/ReaderViewModel.kt:63-67`、`ui/reader/ReaderScreen.kt:659-668` |
| 卡片长按 | 收藏页用于取消收藏、历史页用于删除；首页/搜索/分类/作者页网格尚未占用 | `ui/browse/ComicGridView.kt:100-104,163`、`ui/history/RecentReadsScreen.kt:185`、`ui/author/AuthorFavouritesScreen.kt:150` |
| 剪贴板能力 | 仅日志页直接用 `ClipboardManager`，无公共工具 | `ui/settings/LogScreen.kt:105-107,131-132` |

### 1.3 现有缺口

1. **只能整段分享，不能单独复制**：想把作品名粘到搜索框，只能先分享再删掉多余内容。
2. **标题/作者是不可选文本**：长按没有系统文本选择菜单，用户只能手打。
3. **复合署名容易复制错**：`BlossomSphere (桜湯ハル)` 这类署名，手动输入括号、空格、日文都易错。
4. **列表卡片不适合放长按复制**：收藏/历史的长按已经是「取消收藏/删除」这类管理动作；若在首页/搜索另做「长按复制」，同一个手势在不同列表语义不一致，容易误触。

## 2. 设计目标与非目标

### 目标

- **G1 两步内可达**：详情页通过「更多」菜单两步复制；长按文本一步直达。
- **G2 零点击语义变更**：作者行点按仍进作者页/选择层；标题点按仍无动作；卡片点按仍进详情。
- **G3 所见即所得**：不解析、不删改、不补全；复制值就是页面上展示的完整值（显示被省略号截断时也复制完整值）。
- **G4 可发现且可访问**：有可见入口；TalkBack 可通过自定义操作触发长按复制。
- **G5 零副作用**：不新增权限、不发网络请求、不写持久化、不改变分享文案。

### 非目标（本期不做）

- 不做文本选择/局部框选（短标题用不上，长按拖选反而难操作）。
- 不做全站列表卡片的长按复制（见 §3，列为 P2）。
- 不复制章节名、封面图、作品链接。
- 不做「复制作品信息（标题+作者）」——分享已覆盖组合场景。
- 不做剪贴板历史、自动复制、打开页面即复制。
- 不做多选批量复制作者名。

## 3. 覆盖范围与分期

| 优先级 | 页面 | 复制内容 | 入口 | 说明 |
|---|---|---|---|---|
| **P0** | 作品详情页 | 作品名 / 作者名 | 顶栏「更多」菜单 + 长按文本 | 作品身份最权威的页面，作者选择层也在这里 |
| **P0** | 作者页 | 当前作者署名 | 顶栏复制图标 + 长按标题 | 作者身份最权威的页面；切片段后复制值跟随 |
| **P1** | 作者页 | 完整原署名 | 长按「原署名」提示行 | 仅在复合署名、且当前浏览片段≠完整署名时出现 |
| **P1** | 阅读器面板 | 作品名 / 作者名 | 面板顶栏「更多」菜单 | VM 已有数据，但顶栏当前展示章节名，需要额外排版 |
| **P2** | 首页/搜索/分类/作者页卡片 | 作品名 / 作者名 | 长按卡片 → 统一操作面板 | 需与收藏/历史的长按管理动作统一设计，避免同手势多义 |
| **P2** | 下载页作品分组 | 作品名 | 分组「更多」菜单 | 入口已有导出/删除，复制可并入 |

**为什么 P0 不做列表卡片**：列表页的价值是「扫一眼 → 点进详情」，详情页只多一次点击就能复制；而长按在收藏/历史已有破坏性语义。为一个低频复制动作重做全站卡片长按，收益低、误触风险高。等 P0 验证后再评估 P2。

**为什么 P1 才做阅读器**：阅读器是沉浸场景，面板顶栏只放章节名与返回；把「复制作品名/作者名」塞进面板需要重新组织顶栏动作。且离线阅读时详情可能未加载，标题为空，需要空态处理。

## 4. 交互设计

### 4.1 作品详情页（P0）

```
┌──────────────────────────────────────────┐
│ ←   作品标题                    ♡   ↗   ⋮ │
├──────────────────────────────────────────┤
│ [封面]  作品标题（长按复制作品名）          │
│         作者名  查看作品 >（长按复制作者名） │
│         连载中 · 120P · 30 话              │
└──────────────────────────────────────────┘
```

**入口 A：顶栏「更多」菜单（主入口，可发现）**

- 在分享图标右侧新增 `⋮`（内容描述「更多操作」）。
- 点击弹出 Material 下拉菜单：
  - **复制作品名**
  - **复制作者名**（作者为空时不显示该项）
- 菜单项点击后立即关闭菜单、写入剪贴板、弹出 Snackbar。
- 菜单项带复制图标，保证与纯文字菜单有区分。

**入口 B：长按文本（快捷方式）**

- 长按标题（约 500ms）→ 直接复制完整作品名，弹 Snackbar；不弹菜单、不导航。
- 长按作者行 → 直接复制完整原署名，弹 Snackbar；**点按行为完全不变**（单署名进作者页，复合署名弹选择层）。
- 长按有系统触感反馈；长按后抬手不应触发点按动作。
- 标题本身没有点按动作，长按外的手势保持现状（不新增点击响应、不出现无意义的涟漪）。

**状态处理**

| 状态 | 表现 |
|---|---|
| 详情加载中 / 失败（`comic == null`） | 顶栏标题显示「详情」；不显示「更多」菜单；长按无响应 |
| 标题为空 | 「复制作品名」不可用（隐藏或置灰），长按无响应 |
| 作者为空 | 不显示「复制作者名」；作者行本就不渲染，无长按入口 |
| 作者为复合署名 | 复制完整原署名，不做拆分（拆分是作者页的事） |

### 4.2 作者页（P0）

```
┌──────────────────────────────────────────┐
│ ←   BlossomSphere            ⧉    ♡      │
├──────────────────────────────────────────┤
│ [片段 chip] [片段 chip] [完整署名]         │
│ 正在浏览署名中包含「…」的作品 · 原署名：…  │
└──────────────────────────────────────────┘
```

- 顶栏新增复制图标（内容描述「复制作者名」），位置放在收藏左侧，**收藏图标位置不变**。
- 点击复制 `currentQuery`（当前正在浏览的署名），而不是进来时的原始参数；页内切换片段后，复制值立即跟随新片段。
- 长按顶栏标题执行同一动作。
- 新增 `SnackbarHost`；复制成功提示「已复制作者名」。
- 复合署名且 `currentQuery != origin` 时，P1 在原署名提示行提供「复制完整署名」（长按提示行），复制 `origin`。

**为什么不复制完整署名作为默认**：作者页的标题与结果都是「当前片段」，复制标题位置的内容最符合预期；要完整署名可切「完整署名」片段，或走 P1 的提示行入口。

### 4.3 反馈

| 场景 | 反馈 |
|---|---|
| 复制成功 | Snackbar：「已复制作品名」/「已复制作者名」，短时长 |
| 复制失败（剪贴板异常） | Snackbar：「复制失败，请重试」 |
| Android 13+ | 系统自带的剪贴板预览浮层会额外出现；本 App 仍保留 Snackbar，保证低版本与高版本反馈一致 |
| 连续复制 | 每次立即写入；Snackbar 复用同一个 Host，后一条替换前一条，不堆叠 |

- 不使用 Toast（与 App 现有 Snackbar 体系不一致）。
- 不弹确认框（复制是低风险、可重复操作）。
- Snackbar 文案不拼接完整标题/作者名，避免长文本把提示撑成多行；用户可在剪贴板预览或粘贴处确认内容。

### 4.4 可发现性与可访问性

- **可见入口优先**：详情页「更多」菜单、作者页复制图标是主路径；长按是熟练用户的加速器，不依赖用户猜。
- **TalkBack**：长按复制通过 `CustomAccessibilityAction` 暴露为「复制作品名」「复制作者名」，读屏用户无需执行长按手势。
- **触控目标**：菜单项与图标按钮不小于 48dp；作者行长按区域为整行，不要求精确按在文字上。
- **配色**：菜单与图标沿用主题 `primary` / `onSurface`，不新增仅靠颜色表达的状态。
- **不做首次引导气泡**：会增加一次性状态与打断；可见菜单已承担发现职责。

## 5. 复制内容规范

| 入口 | 复制值 | 示例 |
|---|---|---|
| 详情页 · 复制作品名 | `comic.title.trim()` | `君と僕の甘い関係` |
| 详情页 · 复制作者名 | `comic.author.trim()`，完整原署名 | `BlossomSphere (桜湯ハル)` |
| 作者页 · 复制作者名 | `currentQuery.trim()` | `BlossomSphere` |
| 作者页 · 复制完整署名（P1） | `origin.trim()` | `BlossomSphere (桜湯ハル)` |

**规则**

1. **不加装饰**：不带 `《》`、不带「作者：」前缀、不带来源尾注。
2. **所见即所得**：保留内部分隔符、括号、角色说明（如 `（翻译：王五）`）、日文/英文原样；只去掉首尾空白。
3. **不截断**：列表/标题显示用 `maxLines` 省略时，复制仍取完整数据。
4. **不做本地解析**：复制动作不调用 `AuthorNameParser`；拆分只发生在「作者页/选择层」的浏览语义里。
5. **空值不复制**：`trim()` 后为空则不提供入口或无响应，不复制空字符串。
6. **换行**：若源数据含换行，保留原换行，不擅自改成空格。

## 6. 边界与异常

| # | 场景 | 预期行为 |
|---|---|---|
| 1 | 详情页加载中/加载失败 | 无「更多」菜单；长按无响应；不崩溃 |
| 2 | 作品标题为空 | 「复制作品名」隐藏/置灰；长按无响应 |
| 3 | 作者为空 | 不显示「复制作者名」；作者行不存在 |
| 4 | 复合署名（多作者/翻译） | 详情页复制整串；作者页复制当前片段；均不改动原串 |
| 5 | 作者页切换片段 | 复制值跟随 `currentQuery` 变化，无需重新进入页面 |
| 6 | 作者页从旧路由进入（无 `origin`） | `origin` 回落为 `author`，复制 `currentQuery` 正常 |
| 7 | 离线/详情缓存失败 | 页面已有标题/作者时可复制；无网络依赖 |
| 8 | 长按后手指移动 | 识别为滚动/取消，不触发复制 |
| 9 | 长按后抬手 | 不触发原点按动作（不进作者页、不弹选择层） |
| 10 | 快速连续复制 | 每次都写入剪贴板；Snackbar 替换，不排队 |
| 11 | 旋转/进程重建 | 无新增持久化状态；剪贴板内容不受影响 |
| 12 | Android 13+ 系统剪贴板浮层 | 与 App Snackbar 可能同时出现；接受该重复，不视为缺陷 |
| 13 | TalkBack | 通过自定义操作菜单可触发复制；读屏朗读操作名称 |
| 14 | 超长署名/标题 | 完整写入剪贴板；提示文案固定，不随长度变化 |
| 15 | 剪贴板服务异常（极低概率） | 捕获异常，提示「复制失败，请重试」，不崩溃 |
