### 真机测试发现的缺陷（静态审查查不出，已修）
- **F16 的说明文字不可点击**：只有 Checkbox 本体（约 20dp）可点，点「保存账号密码（便于下次一键登录）」文字无反应。小屏上极易被当成「开关坏了」。
- 修法：把 Row 加 `.clickable { toggleSave(!rememberPassword) }`，Checkbox 的 `onCheckedChange` 与 Row 点击共用同一个 `toggleSave` lambda（避免两处逻辑分叉）。
- 修复后实测：点文字能切 false→true→false，覆盖安装后原状态保留。
- **教训：纯复选框交互务必整行可点。** 这类问题只有真机/模拟器能发现。

### MuMu adb 连接坑（重要，下次直接照用）
MuMu 自带 adb server 会与宿主 adb 抢 5037 端口，导致每次冷启动 adb server 后**第一条命令命中 `device offline`**，而且该失败**静默**（`adb shell input tap` 返回空，看不出失败）——我最初两次「输入密码」实际都没执行成功，误以为 App 有问题。
- 解法：封装 `adbwrap.sh`（在 `C:/Users/wacil/AppData/Local/Temp/`，可复用）：
  - `ensure_online()` 循环 `start-server` + `get-state` 校验，兜底改用 `127.0.0.1:16384`（MuMu 桥接端口）；
  - `retry()` 对含 `device offline|not found|no devices` 的输出自动重试；
  - 用 `source adbwrap.sh` 后在每批命令开头调 `ensure_online || exit 1`。
- 排查辅助：`tasklist | grep -iE "mumu|ld9|dnplayer"` 确认模拟器在跑；`adb connect 127.0.0.1:7555|16384|5555` 是 MuMu 常见端口。

### 其它实操要点
- 截图 1440×2560，界面坐标需按比例换算（预览图会被缩放，别照抄预览坐标）。登录页关键 y（1440×2560 下）：邮箱框 779、密码框 996、眼睛 1226/996、复选框 173/1330、说明文字 620/1330、底部 Tab 2570。
- `unzip -l apk | grep lib/` 可确认 ABI 覆盖面（本包含 arm64-v8a / armeabi-v7a / x86 / x86_64）。
- 用 `aapt2 dump badging` + `java -jar apksigner.jar verify --print-certs` 复核版本号与签名（apksigner 需 JDK 跑 jar，`build-tools/*/apksigner.bat` 在 git-bash 下不便用）。
- **设备侧 curl 是验证 CDN 可达性的可靠手段**：同一网络下 host 侧 curl 可能被限速到几乎不可用（实测 4 分钟只下到 15KB），而设备侧同一 URL 23 秒下完 6.2MB。别用 host 侧慢就判定发版有问题。
- `adb root` 在 MuMu 上可用，但它会**重启 adbd**，导致紧接着的命令 device offline；要读 `/data/data/com.pika/` 就单独一批命令里 root，别和后续操作混在一起。
