# 2026-09-02

## 阅读器：进入漫画时隐藏底部导航栏

需求：阅读页已经沉浸式隐藏系统栏，但 App 自己的 NavigationBar（64dp，首页/分类/搜索/我的）常驻，看起来不够全屏。

实现（4 个文件）：
- `data/ReaderPrefs.kt`：新增 `hideBottomBarInReader: Flow<Boolean>`（DataStore key `hide_bottom_bar_in_reader`，默认 true）+ `suspend setHideBottomBarInReader(Boolean)`。用 Flow 而非同步 runBlocking 读写，改设置后 MainScreen 可即时重组。
- `ui/MainScreen.kt`：顶层加 `fullScreenRoutePrefixes = listOf("reader/")`，按 `currentDestination?.route` 前缀匹配 + 开关共同决定是否渲染 `Scaffold.bottomBar`。直接 `if (!hideBottomBar)`，无动画。Scaffold 自动把 64dp 还给内容区。
- `ui/reader/ReaderScreen.kt`：`ReaderControlPanel` 加 `modifier` 参数，调用处传 `Modifier.navigationBarsPadding()`，修掉唤出面板时系统导航条压住亮度滑条/页码的已有问题。
- `ui/settings/SettingsScreen.kt`：新增「阅读」分区 + Switch，存到 ReaderPrefs。

坑：
- `WindowInsets.navigationBars` 在本项目 Compose BOM 2024.12.01 下**无法解析**（需额外 import companion 扩展），改用 `Modifier.navigationBarsPadding()` 编译通过。
- `assembleDebug` 在 120s 前台超时会被 SIGTERM，要用 `run_in_background`。

设计决策（用户确认）：无动画直接隐藏（阅读器纯黑背景，避免 innerPadding 变化导致内容位移）；顺带修 navigationBars 遮挡；加设置开关且默认开。
